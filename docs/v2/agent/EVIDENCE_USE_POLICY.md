# V2 Planning Material: Evidence Use Policy

Not current runtime truth. This policy governs how V2 planning sessions should use repo evidence.

## Required Rules

- Every major claim needs repo evidence.
- Current runtime truth and V2 planning truth must stay separate.
- Journals are evidence, not canon.
- Candidates do not become defaults by repetition.
- If evidence is mixed or missing, classify the item `unknown`.
- Use only these categories:
  - `doctrine`
  - `conditional candidate`
  - `historical reference`
  - `retest-only`
  - `unknown`

## Bad Patterns To Avoid

- promoting candidates to defaults
- choosing backends from familiarity
- turning historical names into V2 architecture identity
- treating pending inventories as proof of absence
- using chronology alone as proof of durability
